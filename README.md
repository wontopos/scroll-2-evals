# Scroll 2 evals

Measurement records for Scroll 2. Records are keyed by each benchmark's own question ids. The benchmarks' questions, reference answers and rubrics are not reproduced here; obtain them from the benchmarks and join.

| folder | what | measured |
|---|---|---|
| [`beam-1m/`](beam-1m/) | BEAM-1M, 700 questions: five runs of the single call, four runs with memory tools, Sleep 1.0.0, Coverage, store size | 28 September to 21 October 2026 |
| [`claude-memory/`](claude-memory/) | BEAM-100K, 400 questions: Claude Managed Agents memory and Scroll 2 | 14 October 2026 |

BEAM is Tavakoli et al., *Beyond a Million Tokens* ([arXiv:2510.27246](https://arxiv.org/abs/2510.27246)), licensed CC BY-SA 4.0. Files here that contain text derived from BEAM conversations (answers, judge reasons, memory contents) are shared under CC BY-SA 4.0.
